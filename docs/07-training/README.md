# Training posters (v2, 2026-07-17)

Three posters, bilingual, print A3. Simplified from six after the UI/reduction overhaul —
the wall should teach exactly what the app now does, nothing more.

| File | Wall message | Hangs where |
|------|--------------|-------------|
| `roles-responsibilities-poster.html` | Who does what at every stage, with the hour clocks. Replaces the old workflow + role-cards posters. | Workshop + office corridor |
| `scores-and-money-poster.html` | The 85% bar, per-role clocks, two worked examples, points rules, the four pools, the floor rules. This is the "four pools poster" the announcement meeting uses. | Beside the notice board |
| `claiming-poster.html` | 我来处理 psychology: two-thing reporting (no names), the 0–24–48h ladder, why taking it builds face. | Where issues happen — assembly + injection halls |

Print: open in a browser → Print → A3, color, background graphics ON.

## What changed vs v1 (why the old ones are wrong now)

- Button is 我来处理 ("I'll take this"), not 认领; the UI shows 处理人 (handler), never 责任人.
- Reporting an issue = title + photo only. No owner named, no severity decision by the reporter (QC sets severity at verification). Auto-routes to the department inbox.
- Escalation ladder is explicit: 0–24h anyone volunteers → 24–48h leader takes/assigns (normal management) → 48h+ leader's miss, red on GM report. QC never assigns.
- Clocks stated in literal hours (24h/48h, weekends count) — not "workdays".
- Hot-3 / lessons library is phase 2 → its poster is parked in `archive-v1/`, do NOT hang it at pilot launch.
- Red/amber urgency stripes in the app are referenced on the roles poster ("红条 = 加急").

`archive-v1/` holds the six v1 posters for reference. The Hot-3 poster returns when the lessons library ships.
