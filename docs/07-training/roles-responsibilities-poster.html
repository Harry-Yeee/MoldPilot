每一步，谁做什么
The mold-trial workflow — who does what, at every step · 时限为小时数，周末照算
STAGE 1
项目立项
Project intake
市场部
创建立项：客户、零件、需求摘要Create the intake: customer, parts, request summary
项目管理
审核立项，录入模具编号，设定首次 T0 日期Review, enter the mold code, set the first T0 date
STAGE 2
排期确认
Date confirmation
项目管理
设定试模日期（T0 / T1 / T2…）Plan the trial date
注塑
确认日期并选定机台；有冲突则说明原因提议新日期≤24小时Confirm date + machine, or propose a new date with a reason
市场部
对照客户交期，批准或退回日期变更≤24小时Approve or return date changes against the customer deadline
STAGE 3
试模当天
Trial day
注塑
执行试模，录入工艺参数（可复制上次参数）Run the trial, enter process values (copy last trial to start)
项目管理
录入试模结果≤24小时；未通过必须登记问题Record the result; failed trials must have issues filed
发现问题的人
登记问题只要两样：一句话 + 一张照片。不选谁的错，不指名任何人——系统自动送到对应部门的收件箱Reporting = one line + one photo. No fault field, no name — the system routes it to the department inbox
质检
检验样品，记录尺寸与外观问题；严重度由质检在验证时定级Inspect samples; QC sets/adjusts severity at verification
STAGE 4
整改循环
Correction loop
各部门
收件箱问题点「我来处理」≤48小时——处理是加分，不是认错；无人认领时组长指派，属正常管理Press "I'll take this" within 48h — handling is credit, not blame; the leader assigns if nobody volunteers
装配
确认整改并给出预计完成日≤24小时；下次试模前完成自检Acknowledge with estimated finish; self-check before the next trial
设计
完成设计变更修订并上传图纸≤48小时Turn around design-change revisions, attach drawings
项目管理
确认整改就绪，安排下一次试模Confirm readiness, plan the next trial
STAGE 5
验证与报告
Verify & report
质检
在试模现场验证整改并记录结论；上传测量报告≤48小时Verify fixes at the trial, record verdicts; upload the measurement report
市场部
下载客户可见文件，发送给客户Download customer-safe files, send to the client
系统
整改未经验证不算完成——下次试模就是裁判A fix only counts after verification — the next trial is the judge
STAGE 6
计数与收尾
Count & close
系统
每次完成的试模计入次数上限（默认 3 次；批准的设计变更 +1）Each completed trial counts toward the limit (3 by default; +1 per approved design change)
项目管理
客户批准后结案；漏录结果次日自动标记，须如实填写原因≤24小时Close on approval; auto-missed trials need an honest reason
手机就是任务清单
打开系统，首页就是你的待办。做完点掉，别的不用管。
Your phone home screen IS your to-do list. Nothing else to find.
红条 = 加急
列表左边的红条表示已超期，黄条表示快到期——先做有颜色的。
Red stripe = overdue, amber = due soon. Do the striped ones first.
照片就是证据
缺陷必须拍照。没有照片是口说，有照片是证据。
Defects need photos. Words argue; photos prove.
如实填写，永不追责
诚实的原因永远不受罚。系统记录的是流程，不是罪状。
Honest reasons are never punished. The system records process, not guilt.
