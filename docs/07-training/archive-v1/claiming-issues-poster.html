认领不是认错
Claiming an issue is not confessing to it
负责人是解决问题的人，不是犯错的人 · The owner is the fixer, not the culprit
认领的意思是：
"这个问题，我来解决"
Claiming means: "I'll handle this one."
认领不代表：
"是我造成的"
It never means: "I caused it."
系统只统计谁解决了问题
从不统计谁造成了问题
The system counts who fixed it — never who caused it.

A problem appears → someone claims it → the fix is verified → the claimer gets the credit.
